# IT Network & Infrastructure Lab

A hands-on learning and practice environment focused on building practical skills in **IT Support, Networking, Systems Administration, Security, Virtualization, and Cloud**.

This repository documents my **100-day IT Infrastructure journey**, where I turn networking and systems knowledge into practical experience through labs, troubleshooting scenarios, and real-world infrastructure simulations.

## 🎯 Focus

- Networking & Troubleshooting
- Windows & Windows Server
- Active Directory, DNS & DHCP
- Linux Administration
- Virtualization
- Network Security
- PowerShell & Automation
- Cloud Fundamentals

## 🛠️ Tools

- Cisco Packet Tracer
- VMware Workstation
- Wireshark
- Windows 11 / Windows Server
- Ubuntu / Kali Linux
- PowerShell
- Git & GitHub

## 🧪 Learning Approach

Every topic follows:

**Learn → Build → Test → Break → Troubleshoot → Fix → Document**

The goal is not only to understand concepts, but to develop practical troubleshooting and infrastructure skills that can be applied in real IT environments.
